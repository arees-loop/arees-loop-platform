## مرفقات الطلبات — ما تم وما يلزم
- الكود: `RequestAttachment` مرتبط بطلب واحد بالضبط، مع قيد DB وFK واسم/نوع/حجم الملف وسجل الرافع ووقت الإرسال.
- Migration: `20261015222500_private_request_attachments` لا تُشغّل ضمن بناء Vercel ولا على Production.
- GET/POST: `/api/request-attachments` بصلاحية مالك الطلب أو موظف مختص مسند إليه، ولا يُقبل مرجع الطلب وحده كإثبات ملكية.
- التنزيل: `/api/request-attachments/[id]/download` يعيد فحص الصلاحية لكل ملف ويقدمه كتنزيل آمن من private Vercel Blob، بلا رابط عام.
- المدعوم JPG/PNG/PDF بحجم 4MB لكل ملف وتحقق أولي من توقيع الملف، حد 20 ملفاً لكل طلب.
- أضيفت الواجهة في `طلباتي` وإدارة النقل والفنادق، مع رسالة مرافقة للمرفقات.
- يحتاج اختبار قاعدة اختبار منفصلة وخصائص التخزين والإشعارات وتأكيد صلاحيات العميل والموظف وصلاحية الملفات؛ لا يعد بناء TypeScript إثبات نجاح مسار التخزين.
